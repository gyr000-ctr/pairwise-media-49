# kmeans

## 题面（可直接粘贴）

k-means++ 颜色量化。约束：初始化必须按 D² 采样（不是均匀随机）且同种子可复现；收敛判据为中心位移 ≤1e-9 或达到迭代上限，收敛后中心必须等于成员均值（误差 ≤1e-12）；空簇必须用最远点重新初始化而不是丢弃；总误差必须随 k 单调不增；必须提供 3 次重启取最优；1 万像素 8 色不超过 300 ms；非法 k、空输入、非有限颜色要可区分报错。验收：cd kmeans && python -m pytest tests -q -k kmeans。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

- 非有限输入分类报错
